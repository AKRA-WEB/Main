# คู่มือติดตั้งและใช้งาน BUYMORETH PWA

เอกสารนี้เตรียมไว้สำหรับการเปิดใช้ BUYMORETH PWA บนอุปกรณ์พนักงาน ให้เริ่มแจกจ่ายหลังผู้ดูแลระบบประกาศ URL ที่อนุมัติและยืนยันการเปิดใช้แล้วเท่านั้น **ห้ามติดตั้งจาก URL ทดสอบในเครื่องหรือ `127.0.0.1`**

## ก่อนติดตั้ง

- ใช้บัญชี BUYMORETH ที่ได้รับอนุญาตอยู่แล้ว การติดตั้งแอปไม่ได้สร้างบัญชีหรือเพิ่มสิทธิ์
- เชื่อมต่ออินเทอร์เน็ตและเปิด URL ของ BUYMORETH Main ที่ผู้ดูแลแจ้งให้ โดยตรวจชื่อเว็บไซต์ให้ตรงกับองค์กร
- PWA รุ่นนี้ทำงานออนไลน์เป็นหลัก ไม่รองรับการบันทึกรายการธุรกิจขณะออฟไลน์
- เมนูอาจใช้ชื่อแตกต่างกันตามเวอร์ชันของเบราว์เซอร์และนโยบายอุปกรณ์ หากไม่พบเมนูติดตั้ง ให้เปิด BUYMORETH ในเบราว์เซอร์ตามปกติและแจ้งผู้ดูแล

## ติดตั้ง

### Windows · Chrome

1. เปิด URL BUYMORETH Main ที่ผู้ดูแลแจ้งใน Chrome
2. เลือกเมนู `⋮` > `Cast, save, and share` > `Install page as app…` หรือเลือกไอคอนติดตั้งข้างแถบที่อยู่ หากมี
3. ตรวจสอบชื่อและเว็บไซต์ BUYMORETH ในหน้าต่างยืนยัน แล้วเลือกติดตั้ง
4. เปิด BUYMORETH จาก Start, Desktop หรือ shortcut ที่ Chrome สร้างให้

### Windows · Microsoft Edge

1. เปิด URL BUYMORETH Main ที่ผู้ดูแลแจ้งใน Edge
2. เลือกเมนู `…` > `More tools` > `Apps` > `Install this site as an app`
3. ตรวจสอบชื่อและเว็บไซต์ BUYMORETH แล้วทำตามขั้นตอนบนหน้าจอ
4. เปิดแอปจาก Start หรือ shortcut ที่เลือกไว้

### Android · Chrome

1. เปิด URL BUYMORETH Main ที่ผู้ดูแลแจ้งใน Chrome
2. แตะเมนู `⋮` แล้วเลือก `Install and create shortcut` > `Install` (บางรุ่นอาจแสดง `Install app` หรือ `Add to Home screen`)
3. เลือกติดตั้งและยืนยันตามหน้าจอ
4. เปิด BUYMORETH จากหน้าจอหลักหรือรายการแอป

ถ้าตัวเลือกติดตั้งไม่ปรากฏ ให้ลองเปิดหน้า BUYMORETH Main โดยตรงในเบราว์เซอร์ที่รองรับและเชื่อมต่ออินเทอร์เน็ต ตรวจ URL กับผู้ดูแลก่อนใช้ หากยังติดตั้งไม่ได้ให้ใช้ผ่านเบราว์เซอร์ตามปกติ

## เข้าสู่ระบบและสิทธิ์

เข้าสู่ระบบด้วยบัญชี BUYMORETH ตามปกติ แอปที่ติดตั้งกับหน้าเว็บใช้ระบบบัญชีและสิทธิ์เดิมขององค์กร การติดตั้งไม่ทำให้เข้าถึงเมนูหรือข้อมูลที่บัญชีไม่มีสิทธิ์ได้ เบราว์เซอร์หรือโปรไฟล์คนละชุดอาจมีสถานะเข้าสู่ระบบแยกกัน

## แจ้งเตือนการรับสินค้า GR

หลังผู้ดูแลเปิดใช้ระบบแจ้งเตือน บัญชี Admin หรือ Supervisor ที่มีสิทธิ์เข้า GR และรับสินค้าหรืออนุมัติ GR จะเห็นปุ่ม `เปิดแจ้งเตือนรับสินค้า` ที่ Main กดปุ่มนี้แล้วอนุญาตในเบราว์เซอร์เมื่อต้องการรับแจ้งเตือนบนอุปกรณ์นั้น ระบบจะไม่ขออนุญาตเองเมื่อเปิดหน้าเว็บ

- แจ้งเมื่อบันทึกรับสินค้าสำเร็จ รวมการรับบางส่วนและรายการส่งตรวจสอบ ไม่รวมการบันทึกร่าง
- กดแจ้งเตือนเพื่อเปิดรายการรับสินค้าและงานรอตรวจสอบผ่าน Main โดยยังต้องเข้าสู่ระบบและมีสิทธิ์ตามปกติ
- กด `ปิดแจ้งเตือนรับสินค้า` เพื่อหยุดรับบนอุปกรณ์นี้ บัญชีหรือเซสชันใหม่ต้องเปิดแจ้งเตือนใหม่ด้วยตนเอง เมื่อผู้ดูแลเปลี่ยนการตั้งค่าสิทธิ์ ให้กลับมาที่ Main และเปิดแจ้งเตือนอีกครั้งหลังระบบตรวจสิทธิ์ล่าสุด
- ถ้าเบราว์เซอร์ปิดกั้นแจ้งเตือน ให้เปลี่ยนสิทธิ์แจ้งเตือนในการตั้งค่าเว็บไซต์ แล้วกลับมากดเปิดอีกครั้ง
- ถ้าขึ้นข้อความรอผู้ดูแลตั้งค่าหรือเบราว์เซอร์ไม่รองรับ ให้ใช้ระบบงานตามปกติและแจ้งผู้ดูแล

แจ้งเตือนนี้ไม่เพิ่มการบันทึกออฟไลน์หรือคิวส่งข้อมูลธุรกิจเมื่อกลับมาออนไลน์

## การอัปเดต

ไม่ต้องดาวน์โหลดตัวติดตั้งใหม่สำหรับการอัปเดตเนื้อหา BUYMORETH ระบบจะแจ้งเมื่อมีเวอร์ชันใหม่ โดยอาจตรวจพบตอนเปิดแอป กลับมาที่หน้าต่าง หรือระหว่างใช้งาน

- บันทึกงานที่กำลังทำให้เสร็จก่อน แล้วกด `อัปเดต` เมื่อพร้อม
- ถ้ามีข้อมูลที่ยังไม่บันทึก ระบบจะแจ้งว่าการอัปเดตจะทิ้งร่างนั้น ให้ยกเลิกและบันทึกงานก่อนหากยังต้องใช้ร่าง
- ถ้าระบบแจ้งว่ากำลังบันทึกหรือตรวจสอบสถานะ ให้รอแล้วลองใหม่ อย่าปิดหรือบังคับรีโหลดระหว่างบันทึก
- ถ้าระบบบังคับให้อัปเดตก่อนบันทึกรายการ ให้ทำตามข้อความเตือน ร่างที่ยังไม่บันทึกอาจกู้คืนไม่ได้
- ชื่อหรือไอคอนบน Start/หน้าจอหลักอาจเปลี่ยนช้ากว่าเนื้อหาในแอป การเปลี่ยนไอคอนไม่ใช่ตัวชี้ว่าเนื้อหาเว็บอัปเดตแล้ว

## เมื่ออินเทอร์เน็ตขาดหรือการบันทึกไม่แน่ใจ

BUYMORETH PWA ไม่มีคิวออฟไลน์ส่วนกลางสำหรับส่งรายการภายหลัง เมื่อออฟไลน์อาจเปิดหรือโหลดข้อมูลไม่ได้ บางโมดูลอาจมีสถานะงานค้างของตัวเอง ให้ยึดข้อความสถานะของโมดูลนั้นและอย่าสมมติว่าระบบจะส่งซ้ำให้อัตโนมัติ

ถ้าหน้าจอค้างหรือการเชื่อมต่อหลุดระหว่างบันทึก ให้กลับมาตรวจรายการหรือสถานะล่าสุดก่อนส่งซ้ำ หากยังยืนยันผลไม่ได้ ให้จดเวลาที่เกิดเหตุและติดต่อผู้ดูแล การส่งซ้ำทันทีอาจทำให้เกิดรายการซ้ำในบางขั้นตอนงาน

## ใช้บนอุปกรณ์ร่วมกันและถอนการติดตั้ง

- บนอุปกรณ์ร่วม ให้กด `ออกจากระบบ` ทุกครั้งหลังใช้งาน แล้วปิดหน้าต่าง BUYMORETH ก่อนส่งต่อเครื่อง
- หากหลายคนใช้เครื่องเดียวกัน ควรใช้บัญชีผู้ใช้หรือโปรไฟล์เบราว์เซอร์แยกกันตามแนวทางขององค์กร
- การถอนแอปไม่ใช่วิธีอัปเดต และอาจมีตัวเลือกให้ลบข้อมูลของเบราว์เซอร์หรือเว็บไซต์ อย่าเลือกคำสั่งลบข้อมูลเว็บไซต์/เบราว์เซอร์หรือเคลียร์ข้อมูลแอป หากไม่แน่ใจให้สอบถามผู้ดูแลก่อน
- อย่าล้าง site data หรือ storage เป็นขั้นตอนแก้ปัญหาแรก เพราะอาจทำให้สถานะในโปรไฟล์เบราว์เซอร์หายไป

## ไฟล์, PDF และการพิมพ์

ใช้ปุ่มอัปโหลด ดาวน์โหลด PDF และพิมพ์ที่มีอยู่ใน BUYMORETH ขณะเชื่อมต่ออินเทอร์เน็ต หากตัวเลือกไฟล์หรือหน้าต่างพิมพ์ไม่เปิดในแอป ให้ลองเปิด BUYMORETH ผ่านเบราว์เซอร์โปรไฟล์เดิม หากยังมีปัญหาให้แจ้งผู้ดูแลพร้อมชื่ออุปกรณ์และเบราว์เซอร์

## แจ้งปัญหาอย่างปลอดภัย

แจ้งผู้ดูแลพร้อมชื่ออุปกรณ์ ระบบปฏิบัติการ เบราว์เซอร์/เวอร์ชัน เวลาโดยประมาณ เมนูที่ใช้อยู่ และข้อความผิดพลาด ห้ามส่งรหัสผ่าน, OTP, session/token, ลิงก์ที่มีข้อมูลลับ หรือภาพหน้าจอที่เห็นข้อมูลพนักงาน/ธุรกิจ
